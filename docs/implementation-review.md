**初期実装レビュー：Python本体とSkillで音声・静止動画の下書きを制作できる**

2026-10-03。テキスト・UTF-8ファイル・PPTXノートの取り込みから、読み補正、VOICEPEAK合成、音声検査、静止動画の出力までをレビューした。確認範囲に残る利用開始の妨げはない。発音と描画の未確認事項を残した成果物は`draft`として扱う。

実装担当とは別のエージェントが、コードの確認と一時ディレクトリ内の偽エンジンによる回帰試験を行った。チーム内レビューであり、外部の第三者監査ではない。実Voicepeakの操作・辞書変更・画面確認は統合担当が実施し、その記録を参照した。

**中断復旧、生成上限、品質表示の問題を修正した**

| レビューで確認した問題 | 反映した修正 |
|---|---|
| 辞書の書き換え直後や復元途中で中断すると、一時辞書が残る | 書き換え前に復旧記録を保存。3ファイルの原本・自分が変更した状態・バックアップを照合し、外部変更があれば復元を止める |
| 別ジョブが未復旧の辞書を使う可能性 | 共通の復旧記録を確認し、キャッシュだけを再利用する再開でも未復旧なら停止 |
| 同一原稿の重複生成で同じ出力先を上書きする | 同じ生成条件をまとめ、完了済み音声をハッシュ照合して再利用 |
| ボイス資産更新後の途中失敗で、新旧の音声が混ざる | 新しい生成開始時に完了状態を無効化。各音声をエンジン・資産・辞書・原稿・設定の組と照合 |
| 分割数の増加や複数候補の予約で生成上限を超える | 段落の初回分割数を固定し、区間位置ごとの最大4回も併用。新規生成の予定数を先に数える |
| 中断した生成が時間上限から漏れる | 開始前に待機時間を記録し、強制中断で実測値がなければその時間を消費扱いにする。次の待機時間は残りの上限までに制限 |
| 聴取承認時に他区間のASR結果が消える | 既存の検査結果を保持して再検査。音声または読み上げ原稿が変われば承認を無効化 |
| 負号・％の欠落やUnicode文字の途中置換を見逃す | 意味を持つ記号の差を要確認にし、結合文字・異体字セレクター・絵文字修飾子などの途中置換を拒否 |
| 音声の承認が済むと、未確認の動画まで合格表示になる | 動画の品質を別に記録し、画面確認が必要な出力は`draft`を維持 |

フォント指定も確認した。明示した既存ディレクトリを、変換用の子プロセスだけに渡す。一時的なFontconfig設定とキャッシュを使い、フォントのコピー・インストールやシステム設定の変更は行わない。

**継続利用の前に、実資料での受け入れ条件を広げる**

初期版の辞書変更は一時適用に限る。検証済み語の共通辞書への永続保存、自然な発音を自動採用するための評価資料と基準、PowerPoint本体による描画経路は今後の課題として残る。読み補正の型・位置が正しくても、意味を保った読みかどうかは別に確認する必要がある。

動画はPDFまたは明示した同梱LibreOfficeから作る静止画方式で、アニメーションや埋め込みメディアの再現を含まない。他の話者、長時間制作、実資料全体のフォント・配置も未評価の範囲がある。次は代表的な資料で聴取と画面確認を行い、受け入れた例と修正が必要だった例を残す。ホスト終了後もAI判断を続ける常駐運転やMCPは、この初期版の完成範囲に含めない。
