# 埋め込み動画とタイミング付きノート

完成物はプレゼン全体のMP4です。静止スライドのPDFへ、原本PPTXから取り出した動画を元の位置に重ねます。PPTXやそのノートを書き換えず、動画の再生速度も変更しません。

## ノートの記法

| 独立した行に書く指示 | 意味 |
|---|---|
| `【再生前】` | 続く文章を読み終えてから動画を開始する |
| `【動画を再生】` | このスライドの動画を1回再生する。説明付き動画でこの記法を使う場合に1つ必要 |
| `【0:30付近】` | 動画開始から30秒で続く文章を読み始める |
| `【1:45付近】` | 動画開始から105秒で続く文章を読み始める |
| `【再生後】` | 動画終了後、最終フレームを表示したまま続く文章を読む |

時刻は半角の`分:秒`で、秒は00〜59です。複数の時刻は昇順で重複しないようにします。「付近」は指定秒への配置で、映像の内容から場面を検索しません。指示行と本文は分けてください。PowerPoint内の通常の段落区切りと、Shift+Enterの改行の両方に対応します。

`【動画を再生】`の直後に時刻指定なしで本文を置くと、動画の0秒から読み上げます。前後の説明は省略できます。動画スライドに説明文がある場合は、この記法で再生との関係を指定してください。ノートが完全に空なら、説明なしで動画全体を再生します。

読み候補の抽出・読み補正・140文字以内への分割は、本文だけに適用します。指示行は原文として保持し、音声には含めません。動画入りの既存ジョブを古い版で作った場合は、新しいジョブで解析し直してください。

## 音声と時刻の検査

TTSの実測時間を使います。前置きの長さは動画の開始時刻を後ろへずらしますが、`0:30`などの動画内時刻は変わりません。各区間の読み上げが次の区間に重なる場合や、動画の末尾を越える場合は停止します。原稿を短くする、指示時刻を見直す、合成速度を明示的に変更するなどしてから再生成します。末尾を切る、重ねて話す、動画を自動で減速する処理は行いません。

読み方だけの修正は`apply-decisions`で行います。時刻指示や本文自体を変更する場合は、原本を保管したうえで別のPPTXへ編集内容を保存し、新しいジョブで`analyze`してください。保存済みジョブの`source.pptx`や`job.json`を直接変更して、原文との照合を回避しないでください。

元動画の音声は、TTS中だけ既定で18 dB下げます。`export-video --duck-db -24`で24 dBに変更できます。指定範囲は-60〜0 dB、0は減衰なしです。短いフェードで音量を切り替えます。動画に音声がなければ、指定時刻にTTSだけを配置します。合成でクリッピングが生じる場合の出力ゲインと実際の配置はタイムラインへ記録します。

`video/timeline.json`と出力映像で、前後の説明、動画の開始、各説明の時刻、音量の復帰、スライドの切替を確認してください。ASRや時刻の一致だけで、聞き取りやすさや発音の自然さを合格扱いにしません。

## 対応範囲

1スライドに1本の埋め込み動画を対象にします。通常の矩形配置に対応し、グループ化、回転・反転、動画の切り抜き、PowerPoint側の再生範囲変更、複数動画、外部リンクは対象外です。動画の前面に別の図形が重なるなど、PDFを背景にした合成で見た目を再現できない場合も停止します。動画形式はインストール済みFFmpegでデコードできる必要があります。

動画の縦横比とPowerPoint上の配置枠が異なる場合も、見た目を勝手に変えず停止します。動画ファイルは2 GiB以内・4時間以内で、映像1トラックと音声0〜1トラックを対象にします。音声はモノラルまたはステレオに対応し、完成MP4へステレオで合成します。映像と音声の開始位置がずれたファイルや、回転情報付きの動画は、先に通常の再生形式へ変換してください。

PowerPointのアニメーション、画面切替、クリック操作、独立した音声オブジェクトは再現しません。動画の位置と背景のPDFの対応を保つため、同じ原本から、非表示スライドを含む全ページのPDFを用意してください。非表示スライドの音声も生成しますが、完成MP4への収録は`--include-hidden`で選びます。

出力は既定1920×1080、`--resolution`で変更できます。スライドを画面内へ収め、縦横比が異なる場合は黒余白を付けます。解像度や音量の減衰だけを変える場合、既存のTTSを再利用して再出力できます。
