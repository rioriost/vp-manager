**継続実装レビュー：検証済み辞書の保存と、受入音声の参照基盤**

2026-10-03。初期実装に続き、辞書への永続追加、聴取承認の再利用、参照音声の評価をレビューした。確認した不具合は修正済み。自然さを未聴取の音声へ一般化して判定する機能は、今回の完成範囲に含めない。

実装担当とは別のチーム内エージェントがコードを確認し、一時ディレクトリの辞書と偽エンジンで試験した。試験の承認記録は動作確認用であり、実音声を聴取して受け入れた証拠ではない。このレビューでは、実VOICEPEAKの起動や実辞書への永続追加を行っていない。

**承認と保存対象の取り違えを防ぐ**

永続追加には、生成時の辞書原本、追加語、実際に読み上げた区間、音声、エンジンと音声資産が揃っている必要がある。追加する各語が現れる区間を再検査し、現在の音声に対する聴取承認を確認する。未使用語、未承認の区間、語の一部だけの一致では登録できない。たとえば`OpenAI`中の`AI`だけを、辞書語`AI`の使用実績として扱わない。

| レビューで確認した問題 | 反映した修正 |
|---|---|
| 同じ音声と表記に古い承認が残り、辞書の読み変更を見逃す | 承認を音声・表記・辞書適用後の期待する読み・生成条件の組に結び付ける |
| 旧形式のジョブは、生成済み音声を再利用しても辞書の証跡が補われない | 現在の辞書と生成条件を照合した再開時に、不足する証跡を補完する |
| 辞書保存中の一時的な外部変更が、古い読込結果へ混入し得る | 候補辞書を、ハッシュ確認済みのバックアップから構築する |
| 参照音声の索引保存前に中断すると、再実行時の日時差で登録できない | 保存済みの音声・記録を検証して索引へ戻し、最初の聴取記録を保持する |

辞書は`committed`の復旧記録が永続化された時点で保存完了とする。それ以前の中断は辞書3ファイルを原本へ戻し、完了後は戻さない。同じ依頼を再実行しても、後から追加された語や再生成された派生ファイルを古い状態へ上書きしない。未知の外部変更や証跡の破損があれば、原本を保持して復旧判断を求める。

先行の重点確認では、次の試験が116件すべて成功した。うち独立レビューで追加した23件は、プロセスの強制終了、保存完了後の再実行、外部編集、壊れた保存証跡、未使用語、部分的な聴取承認、古い承認の失効、参照データの破損を確認している。追加した試験のRuff検査も通過した。


参照音声は、音声のバイト列、表記、期待する読み、生成条件、原稿全体と対象区間の文脈が一致するときだけ受入記録を再利用する。変更や未登録の条件は`unknown`となる。評価処理は一致数、判定保留数、ラベルとの不一致を報告し、`calibrated: false`と`naturalness_inference: false`を維持する。既知の音声への一致数を、未知の音声に対する発音精度として扱わない。

**CLI統合とPowerPoint経路を最終確認した**

CLI、ジョブ保存、QA、音声・動画処理と、README・制作Skillを照合した。未承認音声の扱い、辞書保存の条件、参照結果の意味、全スライドPDFの作り方は実装と一致している。今回追加した範囲の導線に、未修正の阻害事項は見つからなかった。

統合担当の実機記録も読み合わせた。通常のPowerPoint出力は2ページ、描画用コピーからの出力は非表示スライドを含む3ページで、表示対象2ページの画素は一致した。非表示ページの画面との目視照合は統合担当が行っている。動画は表示対象のみで146フレーム・5.84秒、全スライドで206フレーム・8.24秒となり、どちらも記録上の映像・音声の時間差は0秒だった。境界を含む9フレームのスライド対応も検査記録と一致する。

実機のゲート確認記録（ローカル記録: `artifacts/continuation/live-gates.json`）では、辞書3ファイルの前後ハッシュが一致し、3ジョブの生成履歴数は2・1・2件のまま増えていない。未承認語の永続保存は拒否され、参照音声の書き出しは0件だった。実機の保存成功を示す試験ではない。詳細は[統合検証記録](continuation-validation.md)を参照する。

**実利用で残る確認事項**

聴取記録は、利用者が明示した判断を保存する仕組みであり、署名付きの外部証明ではない。実音声の受入例・誤読例・判断が難しい例を集め、評価用の資料を分けて自然さの採用基準を決める作業は残る。実辞書への初回登録も、登録する語を使った音声の聴取後に行う。

PowerPoint本体での比較は、3枚の検証資料での結果である。実資料全体の発音・フォント・配置や別の話者は、対象ごとの確認が必要になる。

検証の原稿・音声・実機ログはローカル記録のため、公開リポジトリと配布パッケージには含めない。
