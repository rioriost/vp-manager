# 辞書の確定保存、受入音声の参照、PowerPoint描画の追加検証

2026-10-03。ローカルPython本体とSkillに、聴取済み新規語の確定保存、参照音声の保存・再利用、PowerPoint向け描画コピーの作成を追加した。Astra xhighの監督役とhighの実装担当が分担し、実装担当とは別の試験で修正を確認した。[独立レビュー](continuation-review.md)も参照。

## 追加した処理

| コマンド | 動作と採用条件 |
|---|---|
| `promote-dictionary JOB` | 一時辞書で実際に使った新規語を確定保存する。語が現れる全区間の音声、読み、生成条件、聴取記録、元辞書を照合する |
| `export-references JOB --corpus DIR` | 現在の音声を明示的に聴取して受け入れた記録だけを保存する |
| `verify JOB --corpus DIR` | 音声のバイト列、表記、読み、合成条件、原稿の文脈が一致するときだけ記録を再利用する |
| `reference-list` / `reference-import` / `evaluate-references` | 受入れ・誤読・保留のラベルを管理し、一致・不一致・判断保留を集計する。自然さの推定はしない |
| `prepare-slides JOB` | 原本を保持し、非表示スライドだけを表示にした描画用コピーと、その作成記録を保存する |

参照データの形式は[参照音声の契約](references.md)、制作の手順は[Skill](../.agents/skills/voicepeak-production/SKILL.md)にまとめた。独立したAI APIキーやMCPサーバーは必要ない。判断を担当するホストAIと、決定的な処理を担うPythonの構成を維持している。

## 承認の取り違えと中断を検証した

音声と原稿表記が同じでも、辞書の読みや音声資産が変われば承認は失効する。旧ジョブは、現在の辞書と生成条件が同じことを再確認した`resume`で不足する辞書の記録を補完する。旧形式の承認は`verify`と聴取確認をやり直す。

辞書の成功経路は一時ディレクトリの辞書で試験した。保存処理の各段階で別プロセスを終了させ、確定前は復元し、確定後は保存結果を維持することを確認した。再実行によって、後から登録した語や再生成された派生辞書を古い状態へ戻さない。外部編集や壊れた記録がある場合は、現状を保持して回復待ちにする。

参照音声の保存では、索引を保存する前に中断した場合も、最初の聴取記録を保持したまま再開する。音声や記録の破損、矛盾するラベル、文脈の変更では自動受入れを行わない。これらはローカル記録の整合性検査であり、本当に聴取したかをソフトウェアが証明するものではない。

## PowerPoint本体の描画と全スライド対応

HorizonDBの資料から作成した3スライドの試験用PPTXを使った。2枚目を非表示、3枚目のノートを空にしている。元の資料そのものは変更していない。

PowerPointの通常のPDF書き出しは、非表示を除いた2ページになった。`prepare-slides`で作ったコピーをPowerPointで開き、ローカル処理の「印刷に最適」で書き出すと、全3ページになった。元々表示されていた2ページは、原本からのPDFと画素単位で一致した。非表示だったページも、PowerPointの画面とPDFを目視で照合した。3ページの日本語表示とレイアウトを確認し、原本PPTXのハッシュが不変であることも確かめた。

同梱LibreOfficeの描画には、PowerPoint本体と文字の太さや間隔の違いがあった。元の見た目を重視する場合は、PowerPointが書き出したPDFを使う。PowerPointのGUI書き出しはホストの画面操作または利用者が担当し、Python内の無人バックエンドとしては実装していない。

## 到達点と残る作業

テキスト・PPTXから確認用音声と静止動画を作り、聴取結果を記録し、実際に使った新規語を保存する経路を実装した。最終実行ではPython・CLIの209テストが成功し、Ruff、Skillの形式検査、配布用wheelとソースアーカイブのビルドも通過した。README、Skill、この文書と参照音声の説明は日本語lintの指摘が0件だった。

未知の音声の発音・アクセント・自然さを自動で合格判定する機能は残っている。参照音声との完全一致だけでは、新しい原稿の品質を評価できない。実音声の受入例・誤読例・判断保留例を集め、評価用データを分けて採用基準を検証する必要がある。実辞書への初回確定保存も、対象音声の実際の聴取を得てから確認する。

今回の動画は技術検証用の短い原稿であり、資料全体の完成ナレーションではない。聴取未確認のため`draft`を維持している。任意の資料・話者での完全無人制作や、動画全体の視覚的な合格判定まで完成したとは扱わない。

検証の原稿・音声・実機ログはローカル記録のため、公開リポジトリと配布パッケージには含めない。
