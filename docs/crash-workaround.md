# VOICEPEAK異常終了への対策

2026-10-04、macOS版VOICEPEAK 1.2.23を対象に調査・実装した。原文と既存の音声を保持して、問題のある区間以外の制作を進めるための回避策である。VOICEPEAK内部の原因を特定した修正ではない。

## 確認した事実

- 10月3日22時台と10月4日6時台のクラッシュ記録は、VOICEPEAK内部の同じ先頭スタック位置で`EXC_BAD_ACCESS` / `SIGSEGV`を示した。これだけでは、かぎ括弧や引数が直接原因とは特定できない。
- 旧アダプターもシェルを使わず引数配列で起動していた。Python側のシェル引用ミスは確認されていない。一方、本文を`--say`の引数から外せば、本文をコマンドライン引数の処理経路から外せる。
- 保存済みの制作ジョブ2件に残る8件の異常終了を調べると、7件は日本語かぎ括弧を含んでいなかった。括弧処理だけで全件を解決できる根拠はない。元ジョブは変更せず、履歴の照合のみ行った。
- 旧分割では、140文字を超える引用文や改行をまたぐ引用文を、片方のかぎ括弧だけを含む区間へ分けていた。閉じかぎ括弧だけの区間も生成された。
- 旧アダプターは、終了後のGUI確認より後に診断を保存していた。確認が失敗すると終了コードや標準エラーが残らない経路があった。

## 変更した動作

本文は0600のUTF-8一時ファイルへ、BOMや改行を追加せず保存する。VOICEPEAKには`--text input.txt --out output.wav`を渡し、非公開の一時ディレクトリを作業場所にする。ジョブパスの空白・引用符も引数へ露出させず、検証できたWAVだけを同一ファイルシステム内で原子的に公開する。

`source_text`と利用者の`spoken_text`は保持する。合成用`engine_text`では`「」『』`だけを空白へ置換する。変換は140文字への分割前に行い、文字位置・変換規則版・前後のSHA-256を`engine_preparation`へ記録する。位置は読み補正後の文字列を基準とし、原文に対する読み判断の位置とは区別する。引用部分の文字、数値、符号、アポストロフィは消さない。タイミング指示行は除外する。

`render`と`resume`は旧ジョブにも同じ準備を適用する。成功済みの同じ入力・生成条件・辞書・音声ハッシュは再利用する。再計画でチャンク番号が変わっても、履歴や試行予算は消さない。変換により実入力が変わった区間は生成できるが、同じ失敗入力の自動反復は行わない。輸送方法の変更だけでは過去の失敗を解除しない。

エンジンの合成エラーは履歴へ保存し、プロセス終了、別GUI不在、辞書の整合性を確認してから後続を生成する。同じ本文が後続へ重複していても、失敗済みなら繰り返さない。環境エラー、タイムアウト、割込み、辞書競合ではその場で停止する。終了時にはvp-managerが起動したプロセス群だけを回収し、起動前から開いていたGUIや別のプロセス群は終了しない。

失敗が残るジョブは非ゼロで終了し、全体の完了記録を作らない。`failed_chunks`と`render_progress`で失敗・完了・未実行数を確認できる。履歴の`diagnostics`には終了コード、シグナル、タイムアウト、標準出力・標準エラーの末尾、プロセス回収結果を残す。部分音声をQA・結合・動画出力へ進めず、読み補正後に再開する。変更後の音声は改めてQAと聴取確認を行う。

## 実機確認

回帰テスト全体は482件成功し、Ruff、差分検査、同梱Skillの検証も通過した。別担当による130件の統合検証とレビューでは、途中停止時の進捗保存と、プロセス停止確認に失敗した場合の継続禁止を再現条件付きで確認した。

最初の確認では、UTF-8ファイル入力の平文、日本語かぎ括弧、ASCII引用符、`--pitch -100`の4ケースがすべて終了コード0でWAVを生成した。このため、括弧を含む入力が必ず失敗するとは言えない。負のピッチは既存の2引数形式を維持した。検証前後に3つの辞書ファイルの内容を照合し、元のバイト列への復元を確認した。

修正版の通し確認では、空白・ASCII引用符・日本語を含むジョブパスから3区間すべてを生成できた。再開時の合成呼び出しは0件で、音声ハッシュも保持された。原稿のバイト列と3つの辞書ファイルも一致した。ASRの内容照合は2区間で一致し、ASCII引用符を含む1区間では「引用符」が「銀曜符」と文字起こしされ、差異を検出した。聴取による読みの確認は行わず、3区間とも`draft`とした。

再現用プロセスによるテストと実機確認のローカル記録は`artifacts/crash-workaround-20261004/`に保存する。クラッシュ記録、原稿、音声、辞書バックアップは公開配布物へ含めない。保存済みの制作ジョブは読み取りだけに留め、実際に異常終了した入力を繰り返す試験は行っていない。

この対策は、未知のVOICEPEAK内部不具合や自然さの保証にはならない。読み落としの確認には音響検査とASRを使い、最終的な発音・間・イントネーションは聴取で確認する。
