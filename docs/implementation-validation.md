# Python本体とSkillの初期実装を実機で検証した

2026-10-03。Astra・xhighを監督・独立レビュー役に置き、highのサブエージェント2体が実装を分担しました。親エージェントがCLI、工程管理、QA、実機検証を統合しました。詳細な指摘と修正は[独立レビュー](implementation-review.md)に残しています。

この文書は初期実装時点の記録です。同日後続の辞書確定保存、受入音声の参照、PowerPoint描画の照合は[追加検証](continuation-validation.md)に記載しています。末尾の残作業一覧も初期時点のものです。

**テキスト、辞書による読み、PPTXノートから音声付きMP4まで、実装したCLIで一連の処理が動きました。** 発音と自然さの聴取受入れは行っていないため、生成物は`draft`です。利用者の既存原稿と辞書は保持しています。

## 実装済みの範囲

| 処理 | 実装内容 |
|---|---|
| 入力 | テキスト直接入力、UTF-8ファイル、PPTX本文ノート。リレーション順、非表示・空ノート・静止画化の制限を記録 |
| 読み | 英字・数値単位・記号付き語・ユーザー辞書語の候補抽出。原文の版と位置に紐づくかな補正、品詞・アクセントの検査 |
| 合成 | 読み補正後の140コードポイント分割、話者・入力の事前検査、タイムアウト、原子的WAV出力 |
| 辞書 | 新規語の一時追加、3ファイルの退避・復元、永続ジャーナル、外部変更検出、強制中断後の復旧判定 |
| 再開 | 原文・音声・辞書・エンジン・ボイス資産のハッシュ、候補履歴、同一入力の失敗反復防止 |
| QA | 音響検査、期待文を渡さないローカルASR、数字・符号等の相違、音声と期待文に紐づく聴取受入れ |
| 制限 | 原文段落内の区間位置ごとに初回を含む4回。段落全体も最初の区間数×4回で固定し、再分割で上限を増やさない。合成時間予算も保持 |
| 音声結合 | 元サンプルを保持し、段落・スライド間に無音を追加。自動トリミングなし |
| 動画 | 全スライドPDFまたは同梱LibreOfficeから静止画化。非表示の選択、フレーム単位の時間、FFprobe検査、代表フレーム出力 |
| Skill | 本体CLIの操作、全件の判断JSON、局所修正、QAとdraftの扱い、復旧手順 |

原文への置換検査は位置と形式の検査です。かな表記が意味を正しく保っていることまで機械的に証明しません。数値・単位・否定・固有名詞の意味は、Skillの判断と実際の音声で確認します。

## 自動テストとパッケージ

Python 3.12.13の独立した`.venv`と`uv.lock`を作成しました。voice-modelの実行環境には依存しません。実機ASRでは既に取得済みのローカルモデルだけを参照しました。

- `pytest -q`：106件成功。
- `ruff check src/vp_manager tests`：成功。
- `uv build`：wheelとsource distributionを生成。
- Skillの`quick_validate.py`：成功。模擬エンジンによるSkillの別エージェント検証も成功。

テストには辞書処理中の実プロセス強制終了、復元途中の中断、外部編集、バックアップ破損、再分割による生成上限の迂回防止、同文の重複生成防止、辞書・ボイス変更による再生成、聴取受入れの失効が含まれます。エンジン失敗のテストは模擬プログラムで行い、利用者の設定を変更しません。

FFmpegの実エンコードは25fpsと29fpsで検査しました。PCM16音声をPCM24へ結合しても元サンプルが一致すること、段落内の分割には不要な無音を挿入しないことを確認しています。

## VOICEPEAK 1.2.23の実測

`doctor`で1.2.23と7話者、12個のボイス資産を確認しました。実機合成は`Japanese Female 1`を使い、新規に5区間を生成しています。

| ジョブ | 入力と結果 |
|---|---|
| text | 日本語2段落。ASRは期待原稿と句読点以外が一致。段落間へ0.4秒を追加し、6.3707秒のWAVを生成 |
| dictionary | 架空の英字語を新規固有名詞として一時登録し、`Tier-1`は読み上げ用コピーだけ`ティアワン`へ置換。ASRは「桜餅を確認します。Tier1の説明です。」 |
| pptx | 3枚の検証用コピー。2枚目を非表示、3枚目を空ノートにし、全スライドを対応付け。2区間を生成し、空ノートは無音表示 |

textジョブを`resume`したところ、合成履歴は2件のままで、音声・QA・結合済み成果物を再利用しました。dictionaryジョブ後の`dic.json`・`user.dic`・`user.csv`は、処理前とSHA-256がすべて一致しました。VOICEPEAKのGUIは再び開いて構いません。

読みの表記揺れや自然さの判断を自動合格にはしていません。上記は実際のASRと音響検査の結果であり、主観的な聴取受入れの代用ではありません。

## PPTXからMP4までの実測

既存のHorizonDB資料から3枚を取り出した検証用コピーを使いました。ノートは処理の確認用に短い日本語へ置き換えたため、動画の音声はスライド内容の説明ではありません。既存資料自体は変更していません。

最初の同梱LibreOffice出力では日本語の欠字が発生しました。フォントの探索先にMacのフォントとPowerPoint同梱フォントを指定すると、日本語が表示され、Calibri・Georgia・Meiryo UIがPDFへ埋め込まれました。設定は変換プロセスだけに適用し、フォントのインストールやコピーはしていません。[Fontconfigの設定仕様](https://fontconfig.pages.freedesktop.org/fontconfig/fontconfig-user.html)

全3ページのPDFを作り、既定の表示スライド2枚からMP4を生成しました。非表示スライドの音声も保存されています。非表示スライドのPDF出力には、公式の`ExportHiddenSlides`設定を使います。[LibreOfficeのPDF出力設定](https://help.libreoffice.org/latest/en-US/text/shared/guide/pdf_params.html)

- 解像度1280×720、25fps、146フレーム。
- 映像5.84秒、音声5.84秒。時間差0秒。
- 2枚目の表示開始はフレーム71、2.84秒。空ノートの表示時間は3秒。
- 生成MP4から取り出した全表示スライドの代表フレームを目視し、日本語の表示を確認。
- 元PPTXとジョブ内の原本コピーはハッシュ一致。既存資料のノート・スライドは不変。

PowerPoint本体による描画とは比較していません。静止画ではアニメーション・埋め込み動画を保持しません。動画出力は`visual_review: required`を返し、音声が受入れ済みでも動画全体を自動合格にしません。
